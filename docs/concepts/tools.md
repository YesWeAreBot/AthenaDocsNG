# 工具与资源

这个页面讲机器人能做什么，而不只是能说什么。

## 工具是什么

工具是机器人可以执行的动作。没有工具时，机器人只能生成文字；有了工具，它可以读取文件、搜索网页、发送消息、识别图片等。

## 核心工具

以下工具由 YesImBot 自带：

| 工具 | 作用 |
| --- | --- |
| 读取资源 | 读取图片、文件或工作区内容 |
| 发送消息 | 向其他频道发送消息 |
| 描述图片 | 用视觉模型描述图片内容 |
| 结束本轮 | 在不发送文字的情况下结束回复 |

## 插件带来的工具

安装功能插件后，机器人会获得更多工具。例如：

- 搜索插件：联网搜索；
- 工作区插件：读写文件、运行命令；
- 贴纸插件：查找和发送表情；
- OneBot 工具：设置精华、OCR、表态等。

## 机器人如何输出消息

机器人输出时可以使用一些特殊元素：

- 提及某个人；
- 引用某条消息；
- 发送图片或文件；
- 把内容分成多条消息；
- 内部思考，不发送给用户。

这些元素会自动转换成平台消息。

## 资源

机器人发送图片或文件时，通常会使用本地资源：

- 收到的图片；
- 工具生成的文件；
- 工作区文件；
- 技能文件。

资源读取和发送有大小限制，避免机器人一次处理过多内容。

## 图片预算

```yaml
imageInput:
  maxCount: 3
  maxBytesPerImage: 5242880
  maxTotalBytes: 10485760
```

这几个数字分别控制：最多几张图片、单张最大多少字节、总共最大多少字节。
